LinSticky 2.1.0 adds adjustable note transparency to this fork.

### What's new

- Set **Note opacity (%)** in Settings from 20% to 100%.
- Notes become fully opaque when hovered and return to the configured opacity when the pointer leaves.
- Saving settings updates all open notes immediately, without a restart.
- The setting persists across sessions and applies to new notes.
- The default remains 100% opacity, preserving existing behavior.
- Invalid opacity settings are normalized so notes remain visible.

### Packaging

- Fixed the Debian build by removing a malformed, redundant installation hook. Runtime dependencies are declared in the package metadata.
- Builds use a fresh staging directory and exclude Python bytecode caches.
- Tagged releases run configuration and GTK integration tests before publishing the DEB package and `SHA256SUMS`.

### Install

Download `io.linsticky.app_2.1.0_all.deb` and run:

```bash
sudo apt install ./io.linsticky.app_2.1.0_all.deb
```

Quit any running LinSticky instance before launching the updated application.
Open **Settings**, set **Note opacity (%)** to a value such as **60**, and click **Save Settings**.

This release is compatible with 2.0.x note data. The existing limitation for legacy PyQt6 1.x notes still applies: they are not migrated automatically.

The upstream Snap Store package does not include this fork's changes.
