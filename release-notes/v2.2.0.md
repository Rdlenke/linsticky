LinSticky 2.2.0 fixes automatic continuation of bulleted lists.

### What's new

- Press **Enter** after a bullet item to start the next line with a bullet automatically.
- Press **Enter** on an empty bullet to end the list.
- Use **Shift+Enter** for a plain line break.
- Enter also works with the numeric keypad, in the middle of an item, and when replacing selected text.
- Existing text formatting and saved notes are preserved; no data migration is needed.

### Validation

- Added GTK regression tests covering bullet creation and continuation, empty items, cursor position, selections, modifier keys, undo/redo, and saved formatting.
- The release workflow runs these tests alongside the existing opacity tests before publishing the DEB package and SHA-256 checksum.

### Install

Download `io.linsticky.app_2.2.0_all.deb` and run:

```bash
sudo apt install ./io.linsticky.app_2.2.0_all.deb
```

Quit any running LinSticky instance before launching the updated application.

This release is compatible with 2.x note data. Legacy PyQt6 1.x notes are not migrated automatically.
The upstream Snap Store package does not include this fork's changes.
